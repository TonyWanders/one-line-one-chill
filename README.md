A program that writes one line of horror to `/output/entry.txt`,
for the make.fun competition
[One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 116 characters, inside the 1 to 200 gate.

## The line

```
The photo booth printed four pictures of me alone in the booth, and in the last one someone else is holding my hand.
```
